## 1. Paper Reflection: Hidden Technical Debt in Machine Learning Systems

*Reference: Sculley et al., "Hidden Technical Debt in Machine Learning Systems" (NIPS)*

Machine learning systems allow rapid feature deployment, but incur substantial long-term maintenance costs. Technical debt in ML systems exists primarily at the system level rather than the code level. Key factors include:
- **Boundary Erosion**: ML models create complex couplings where "Everything Changes Anything" (CACE principle).
- **Data Dependencies**: Hard-to-trace data dependencies lead to silent system degradation when upstream schemas shift.
- **Feedback Loops**: Deployed models alter future training data distributions.
- **Geographic & Distribution Shift**: Models trained in one environment often experience performance drops when deployed across shifting real-world distributions.

## 2. Methodology & System Implementation

### 2.1 Custom K-Means Classifier
The project implements a custom `KmeansClassifier` class with:
- **Multi-Start Random Initialization**: Runs $10$ independent random centroid initializations (`random_inits=10`) to avoid local minima.
- **Centroid Convergence**: Iterates up to $50$ update steps (`max_iter=50`) per run.
- **Sum of Squared Errors (SSE) Selection**: Retains the clustering configuration yielding minimal SSE.
- **Majority Class Label Assignment**: Assigns target binary pollution labels (`PM_HIGH`: 1 vs 0) to clusters based on majority voting.

### 2.2 Dataset & Features
- **Training Cities**: Northern Chinese cities — Beijing (`Beijing_labeled.csv`) & Shenyang (`Shenyang_labeled.csv`).
- **Evaluation Cities (Distribution Shift)**: Southern Chinese cities — Guangzhou (`Guangzhou_labeled.csv`) & Shanghai (`Shanghai_labeled.csv`).
- **Features**: Meteorological & environmental variables (`DEWP`, `HUMI`, `PRES`, `TEMP`, `Iws`, `precipitation`, `cbwd_NE`, `cbwd_NW`, `cbwd_SE`).

## 3. Experimental Results & Discussion

### 3.1 Accuracy Benchmarks
- **Validation Accuracy (Beijing & Shenyang Test Split)**: **77.37%**
- **Out-of-Distribution Evaluation Accuracy (Guangzhou & Shanghai)**: **87.01%**

### 3.2 Key Takeaways & Observations
1. **Counter-Intuitive Distribution Shift Performance**: The classifier achieved higher classification accuracy ($87.01\%$) on the out-of-distribution southern cities than on the in-distribution validation split ($77.37\%$).
2. **Environmental Explanations**: Southern cities experience more distinct seasonal climate boundaries (humidity/precipitation extremes), making high-pollution clusters more linearly separable in feature space.
3. **Model Limitations & Future Extensions**:
   - Hyperparameter tuning ($k$, number of random restarts).
   - Evaluation metrics: Substituting inertia/SSE with Silhouette coefficients to optimize cluster separation.
