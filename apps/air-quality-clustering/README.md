# Air-quality Clustering Experiment

An experiment using air-quality data from Beijing and Shenyang for training and Guangzhou and Shanghai for evaluation. The report implements and evaluates a K-means classifier while discussing dataset shift and ML maintenance concerns.

## Contents

- [source-listing.md](source-listing.md): extracted code-bearing pages
- [report-extracted.txt](report-extracted.txt): complete searchable report

The implementation expects `Beijing_labeled.csv`, `Shenyang_labeled.csv`, `Guangzhou_labeled.csv`, and `Shanghai_labeled.csv`. These datasets were not included. Dependencies include pandas, NumPy, and scikit-learn.
