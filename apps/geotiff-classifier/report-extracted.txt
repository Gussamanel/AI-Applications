## 1. Introduction & Task Formulation

Satellite and aerial imagery segmentation requires classifying each pixel into land-cover semantic categories. This project builds a PyTorch deep learning pipeline on the Potsdam GeoTIFF dataset to predict $6$ target classes:
1. **Impervious Surface**
2. **Building**
3. **Low Vegetation**
4. **Tree**
5. **Car**
6. **Clutter / Background**

---

## 2. Methodology & PyTorch Implementation

### 2.1 Multi-Spectral Dataset & Augmentations (`GeoTIFFDataset`)
- **Input Channels**: Processes multi-spectral GeoTIFF tiles containing $5$ feature bands (RGB + Near-Infrared + Digital Elevation Model).
- **Target Band**: Channel $6$ ground-truth classification mask.
- **Data Augmentations**: Applied synchronized spatial transformations to feature and target tensors:
  - Random horizontal and vertical flips.
  - Random discrete rotations ($0^\circ, 90^\circ, 270^\circ$).

### 2.2 Spatial Cross-Validation Strategy
To prevent geographic data leakage caused by spatial autocorrelation between adjacent imagery tiles, the dataset is split using **Spatial K-Fold Cross-Validation** (5 folds) based on geographic tile coordinates rather than random tile sampling.

### 2.3 CNN Model Architecture (`LandCoverCNN`)
- **Input Layer**: Convolutional layer accepting $4$ or $5$ input channels.
- **Intermediate Layers**: RelU non-linear activations and spatial convolution blocks.
- **Output Layer**: $6$-channel spatial output logits representing per-pixel class distributions.
