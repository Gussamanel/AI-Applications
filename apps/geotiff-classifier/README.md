# GeoTIFF Classifier

PyTorch image-classification experiments over Potsdam GeoTIFF data. The report includes several model variants, training/evaluation helpers, and a spatial K-fold split intended to test geographic generalization.

## Contents

- [source-listing.md](source-listing.md): extracted code-bearing pages
- [report-extracted.txt](report-extracted.txt): complete searchable report

Referenced inputs include `Potsdam-GeoTif/*.tif`; those data files are not included in this repository. The report also references PyTorch, torchvision, rasterio, GeoTIFF, GeoPandas, scikit-learn, Shapely, NumPy, pandas, matplotlib, and seaborn.
