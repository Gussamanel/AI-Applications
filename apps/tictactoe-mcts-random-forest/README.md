# Tic-tac-toe MCTS with Random Forest Evaluation

A tic-tac-toe agent that combines Monte Carlo Tree Search with a random forest trained on intermediate board states. The report compares the combined agent with a baseline MCTS implementation at different model-weight ratios.

## Contents

- [source-listing.md](source-listing.md): extracted numbered code listing
- [report-extracted.txt](report-extracted.txt): complete searchable report

The report references NumPy, pandas, scikit-learn, and Python's `random` module. Saved training data and model files are not included.
