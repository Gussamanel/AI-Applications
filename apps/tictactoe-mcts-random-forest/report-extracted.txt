## 1. Introduction

Tic-Tac-Toe provides a clear, controllable environment for benchmarking decision-making algorithms. Standard Monte Carlo Tree Search (MCTS) relies on random rollouts to terminal game states, which becomes computationally expensive and inefficient as search space grows.

This project introduces a **Hybrid MCTS + Random Forest Agent**, replacing full random rollouts with value predictions from a Random Forest model trained on intermediate game state snapshots.

---

## 2. Methodology & Pipeline Architecture

### 2.1 Feature Extraction & Dataset Processing
- **Partial State Extraction**: Extracts game state snapshots across move sequences from historical match records (`tictactoe_games.csv`).
- **Label Encoding**: Encodes match outcomes numerically ($X = 1$, $O = -1$, Draw $= 0$).
- **Data Transformation**: Converts $3\times3$ board states into flattened $9$-element feature vectors.

### 2.2 Hybrid Node Evaluation Formula
The Upper Confidence Bound for Trees (UCT) selection policy is modified to incorporate the Random Forest probability output $P_{RF}$ weighted by ratio parameter $\alpha \in [0.0, 1.0]$:

$$\text{Score} = \frac{w}{v + \epsilon} + c \cdot \left( \sqrt{\frac{2 \ln(N + 1)}{v + 1}} (1 - \alpha) + P_{RF} \cdot \alpha \right)$$

- When $\alpha = 0.0$: Standard MCTS behavior (pure rollout/visit statistics).
- When $\alpha = 1.0$: Heuristic-dominated selection guided by Random Forest board predictions.

---

## 3. Experiments & Performance Analysis

### 3.1 Weight Ratio $(\alpha)$ Tuning
- Tested weighting ratio $\alpha$ across $10$ discrete steps from $0.0$ to $1.0$.
- Evaluated win/loss/draw distributions when playing as Player 1 ('X') vs Player 2 ('O').
- Results demonstrate optimal performance around $\alpha = 0.5 - 0.8$, significantly decreasing decision execution time per move while maintaining or exceeding baseline win rates.

### 3.2 Statistical Significance Testing
- Applied exact binomial tests (`scipy.stats.binomtest`) over $200$-game evaluation trials.
- Tested first-move advantage and second-move disadvantage hypotheses against baseline MCTS agents.
- Confirmed statistically significant improvements in win rate ($p < 0.05$) when using hybrid RF evaluation.
