Introduction
Tic-tac-toe is a simple and classic strategy game
where two players face off against each other in
a 3x3 grid where the goal is to get three of their
own marks in a row.
The game serves as sim-
ple yet efficient grounds for testing the decision-
making of AI models. Traditional AI approaches
for the game include algorithms such as Minimac,
Monte Carlo Search Tree (MCST), and other ma-
chine learning-based techniques. In our previous
implementation of the game we implemented an
MCST with an opponent that utilized a completely
random roll-out policy and this led to our model
achieving a 94% win rate. While that is very ef-
fective, we aim to enhance our models ability by
incorporating some machine learning elements to
increase its ability to learn and play the game more
efficiently. Our goal is to implement a random for-
est that will enhance the MCST decision making
ability by providing better-informed evaluations
on board positions.
Our research question:
• How can a Random Forest classifier be im-
plemented into the Monte Carlo Tree Search
algorithm to improve the win rate.
2
Motivation
The MCST relies on random simulations, and this
can lead to semi-optimal move selections espe-
cially in a game where it is facing more complex
opponents. By incorporating a trained random for-
est model the MCST roll-out policy can become
more robust making more strategic and efficient
choices, possibly leading to better gameplay. Our
goal is to evaluate whether the integration of ran-
dom forest with MCST results in a higher win rate
compared to agents that use a traditional MCST
roll-out policy. If our approach results in a higher
win rate it would indicate that decision trees con-
tribute to improved performance, such as was ob-
served in AlphaGo’s approach, which combined
deep learning with the Monte Carlo strategy (Sil-
ver et al., 2016).
Looking past Tic-tac-toe, this project can serve
as a foundation for enhancing AI’s in strategy
games by combining machine learning models
with traditional search algorithms in board games,
real-time strategy games, and AI decision-making
in general. On top of that, dissecting the decision-
making process of the random forest can help
us understand how certain strategies emerge and
what limitations might exist.

3.1
Data:
The dataset contains of 255168 Tic-Tac-Toe
games, with each row representing a complete
match (Therrien, 2024).
The Winner column
records the outcome: ’X’ for player X, ’O’ for
player O, and ’-’ for a draw. Moves are recorded
in columns Move 1-X to Move 9-X, using a row
column format where 0-0 represents the top-left
corner and so on. Unused moves are marked with

3.2
Data preprocessing:
The dataset used in this project consists of Tic-tac-
toe game states and their respective winners. To
prepare the data for usage with the Random For-
est machine learning model (RF) a preprocessing
pipeline was integrated. The following steps were
implemented:
Board state encoding: Each Tic-tac-toe game
board consists of a 3x3 grid. The function con-
vert board to array maps ‘X’ to 1, ‘O’ to -1, and
empty spaces to 0, producing a flattened numeri-
cal array representation of the board to allow the

RF to be able to read the data at each game state.
Feature extraction:
The extract partial states
function extracts different iterations of the game
by iterating through the sequences of moves in
each game and gradually updating the board state.
Each intermediary board state was stored as a
snapshot which allowed the model to train on spe-
cific and individual game iterations rather than
only on completed games.
Label encoding: The winner was encoded nu-
merically as ‘1” for ‘X’, as -1 for ‘O’ and ‘0’ for
draws.
Data transformation: Using the function pro-
cess data the extracted board states, through the
function extract partial states were structured into
a feature matrix X and a respective label vector y
which were then used to train our RF model.

Random Forest Integration:
In order to improve the decision-making of the
standard MCTS implementation a Random Forest
classifier was trained on the preprocessed data and
then integrated into the MCTS UCT algorithms.
The model is in this case trained on all data and
not a standard train test split which in most cases
would lead to overfitting. We did not think this
would be an issue however since the dataset repre-
sents all possible games and we want the model to
learn as much as possible of the entire game. The
implementation includes the following steps:
Model training:

Parameter tuning: The parameter ratio is used to

Integration into MCTS algorithm: The model

4.3
Random Forrest Disadvantages
When testing the various models we noted a few
disadvantages to utilizing the newer more complex
model. Primarily we observed that the model was
significantly slower than the baseline model. De-
pending on the ratio the combined model would be
somewhere between one and two seconds to play
one game while the old model would do the same
in 0.2 seconds. Not significant when we would
play one or two games against the model but test-
ing thousands of games did make this a bit of an
issue. It might also be a limitation if we were to
expand the model to more complex games.
The second thing we observed was that allow-
ing the random forest model have full control of
the decision making led to significantly worse per-
formance in terms of win rate. As seen in figure
1 and figure 2, the model performed worse in both
scenarios. We believe that this is due to the fact
that the random forest model lacks the ability to
plan ahead more than one move. The model has
full knowledge of every board position but does
not value long term strategies which lead to vic-
tory. It only picks boards which are likely to win
which does not appear to be enough to perform
consistently.

5
Limitations
While the approach demonstrates the effective-
ness of integrating machine learning with classi-
cal search-based methods, we encountered several
limitations.
Our MCTS with Random forest implementation
suffers greatly when the decision-making is 100%
on the Random forest. Without the properties of
the MCTS, the Random forest is not capable of
making the necessary decision in order to win.
One limitation we discovered is the inherent
limitations Tic-Tac-Toe has as a game.
Player
X who moves first, has a significant advantage,
which might lead to skewed results in the model
evaluation. What might first seem like a very sta-
ble model with a high win rate might be com-
pletely overturned if the order is switched around.
Since optimal play from both sides would result
in a draw, the model may overfit to specific move
sequences rather than generalize well across dif-
ferent strategies.

The model also suffers from a lack of inter-
pretability as the random forest implementation
in MCTS does not have any maximum search
depth, meaning that it will continue expanding
nodes indefinitely until it reaches its goal. While
this allows for a deeper exploration of possibili-
ties it reduces the interpretability and control over
the computation time.
To try and visualize the
decision-making of the ensemble would require
extremely large computations, time, and power if
it is even possible in that case. On top of that, the
Random Forest model is trained on a large dataset
which may introduce even more complexity when
trying to analyze its decision making pathways.
What we could do is visualize the feature impor-
tance to see what kinds of moves it favors although
it would not give great insight into the overall de-
cision making of the combined model.
Finally, the number of iterations for the MCTS
was set to 500 in order to balance the computa-
tional power required and performance. While in-
creasing the iteration count could perhaps improve
the decision-making even more, the time taken to
simulate would grow significantly. The chosen it-
eration count was deemed enough for our purpose
of the algorithm.

Future work
One potential direction would be to evaluate the
performance of the Random Forest MCTS against
a deep machine-learned-based approach, such as
the neural network used in the AlphaGo (Silver
et al., 2016).
Or maybe another simple deep-
learned model trained on the same dataset. This
could provide insight into whether a more com-
plex model could further improve the decision-
making and generalizability of our model.
Another exploration direction would be to ex-
plore why the Random Forest attains such poor
results when relying on 100% on the decision-
making of the Random Forest while playing Tic-
Tac-Toe.
Lastly, future work could explore ways to im-
prove and refine the integration of the Random
Forest into the MCTS by looking into the weight-
ing of the influence of the Random Forest to find
a way to further optimize the perfect parameters.
Additional search constraints, such as max depth
could be explored to see if the win rate improves
after a certain depth or if the computational cost
stays the same.
7
Conclusion
In conclusion we can evaluate the results of this
paper and see that we partially were able to meet
our goal of improving the Monte Carlo model.
The original question was how the model could
be improved by integrating a random forest clas-
sifier for board evaluation and these results do an-
swer this. Implementing the model by first train-
ing it on a large number of games and then tuning
the search strategy to include the estimated prob-
ability of winning with a specific board can im-
prove the win rate of the overall model. The re-
sults do however show that this only is the case
for the model when playing as player two, show-
ing no statistically significant improvement when
playing as player one. It is also worth noting that
this only was the case after tuning the models de-
cision making as the influence of the random for-
est classifier could in some cases lower the prob-
ability of winning. This suggests that both mod-
els work complementary to one another and that
there is no individual model that has a higher prob-
ability of wining in all scenarios. In this regard
there could certainly be possible to further im-
prove the model and tune more parameters such
as exploration weight, MCTS iterations and vari-
ous parameters of the random forest model as we
do not fully understand what factors contribute to
the combined models success.
