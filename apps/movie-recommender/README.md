# Movie Recommender

A content-based recommender that builds a user's weighted genre profile from ratings and ranks movies using cosine similarity.

## Contents

- [source-listing.md](source-listing.md): extracted code-bearing pages
- [report-extracted.txt](report-extracted.txt): complete searchable report

The extracted code expects `movies.csv` and `user_reviews.csv` with genre feature columns named `genre_*`. Dependencies include pandas, NumPy, and scikit-learn.
