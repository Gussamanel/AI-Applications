## 1. Literature Reflection: The Netflix Prize Challenge

*References: Bennett & Lanning ("The Netflix Prize"), Koren ("Lessons from the Netflix Prize Challenge")*

Key takeaways from the Netflix Prize competition:
- **Cinematch Baseline**: Netflix's baseline system utilized multivariate regression over user ratings.
- **Model Ensembling**: The winning solution demonstrated that combining specialized predictors (matrix factorization, SVD++, neighborhood models) outperforms any single architecture.
- **Auxiliary Data Beyond Ratings**: Incorporating temporal dynamics, user activity frequency, and item metadata significantly improves recommendation accuracy compared to raw rating matrices.
- **Regularization**: Essential to prevent overfitting sparse user-item rating matrices.

## 2. Methodology & System Design

### 2.1 Feature Representation & User Profiling
- **Movie Features**: Extracting one-hot encoded genre indicator columns (`genre_*`) from `movie_genres.csv`.
- **Rating Matrix**: Processing user review ratings from `user_reviews.csv`.
- **User Profile Construction**: Computing a rating-weighted genre preference vector $\vec{u}$:
  $$\vec{u} = \frac{\sum_{m} r_{u,m} \cdot \vec{g}_m}{\sum_{m} r_{u,m}}$$
  where $r_{u,m}$ is the user's rating for movie $m$, and $\vec{g}_m$ is the movie's genre vector.

### 2.2 Cosine Similarity Recommendation Engine
- User profile vectors are normalized and aligned against unrated candidate film genre vectors.
- Candidate items are ranked using Vector Space Cosine Similarity:
  $$\text{Similarity}(\vec{u}, \vec{g}_m) = \frac{\vec{u} \cdot \vec{g}_m}{\|\vec{u}\| \|\vec{g}_m\|}$$

### Critical Deployment Challenges
1. **Pre-Deployment Testing Dilemma**: Offline metrics (RMSE/Precision@K) fail to capture real user satisfaction prior to live deployment.
2. **Implicit vs. Explicit Signals**: Balancing explicit user star ratings with implicit interaction signals (watch time, clicks, completion rate).
3. **Cold Start Problem**: Handling new users with sparse or zero rating histories.
